# laravel-aurora-dsql

Driver de Laravel (12+) para **Amazon Aurora DSQL**.

- Conexión con **token IAM** vía el conector oficial [`awslabs/aurora-dsql-pdo-pgsql`](https://github.com/awslabs/aurora-dsql-connectors) (SSL `verify-full`, reintentos OCC).
- **Schema builder compatible con DSQL**: migraciones normales de Laravel funcionan.
  - `primary()` y `foreign()` / `constrained()` salen **inline** en el `CREATE TABLE`.
  - `index()` / `unique()` → `CREATE [UNIQUE] INDEX ASYNC`, esperando a que el índice termine de construirse.
  - `id()` / `increments()` → `bigint generated by default as identity (cache 65536)`.
  - Sin transacciones de schema (DSQL admite una sola DDL por transacción).
  - `Schema::getTables()`, `db:show`, `db:wipe`, `migrate:fresh` funcionan.
- Clase base `DsqlMigration` para migraciones con SQL crudo.

## Instalación

```bash
composer require jgamboa/laravel-aurora-dsql
```

El service provider se registra solo (package discovery). Agregá la conexión en `config/database.php`:

```php
'dsql' => [
    'driver' => 'dsql',
    'host' => env('DSQL_HOST'),                 // xxxx.dsql.us-east-1.on.aws
    'region' => env('AWS_REGION', 'us-east-1'),
    'username' => env('DSQL_USER', 'admin'),    // 'admin' => dsql:DbConnectAdmin; otro rol => dsql:DbConnect
    'database' => 'postgres',                   // DSQL tiene una sola base por cluster
    'profile' => env('DSQL_PROFILE'),           // perfil AWS local (SSO). Vacío en Lambda/EC2/ECS
    'sslrootcert' => env('DSQL_SSLROOTCERT', 'system'), // 'system' requiere libpq 17+
    'occ_max_retries' => 3,
    'wait_for_indexes' => true,                 // esperar CREATE INDEX ASYNC
    'prefix' => '',
    'prefix_indexes' => true,
    'search_path' => 'public',
],
```

## Uso

```php
// Migración normal (sin SQL crudo)
return new class extends Migration
{
    protected $connection = 'dsql';

    public function up(): void
    {
        Schema::create('productos', function (Blueprint $table) {
            $table->uuid('id')->primary();
            $table->foreignUuid('categoria_id')->constrained()->cascadeOnDelete();
            $table->string('sku')->unique();
            $table->timestamps();
        });
    }
};
```

```php
// Modelo: UUID v7 con HasUuids (Laravel 12+)
class Producto extends Model
{
    use HasUuids;

    protected $connection = 'dsql';
}
```

Transacciones con reintento ante conflictos OCC (SQLSTATE 40001):

```php
DB::connection('dsql')->transaction(fn () => /* ... */, attempts: 3);
```

## Limitaciones de DSQL (verificadas contra un cluster)

| No soportado | Alternativa |
|---|---|
| Agregar PK / FK / UNIQUE / CHECK a una tabla existente | Definirlas en `Schema::create()`; unique → `->unique()` (índice) |
| `ADD COLUMN` con `DEFAULT`, `NOT NULL` o FK | Agregar nullable → `SET DEFAULT` → backfill |
| `->change()` (cambiar tipo), `SET NOT NULL` | Tabla nueva + copia + rename |
| Transacciones anidadas (SAVEPOINT) | Evitar `DB::transaction()` dentro de otra |
| `TRUNCATE` | `delete()` |
| Temp tables, triggers, `plpgsql`, extensiones, advisory locks, `sharedLock()` | — |
| Full-text con config de idioma | Solo `simple` |
| `CREATE DATABASE` | Un cluster por base |

Soportado: `lockForUpdate`, `upsert` (requiere índice único), JSON/JSONB, CTE, window functions, vistas, secuencias, funciones `language sql`.

Notas operativas: conexiones de máximo 60 min (procesos persistentes deben reconectar); el token IAM se firma localmente (sin llamada de red).
